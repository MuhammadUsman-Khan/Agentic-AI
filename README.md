# 🤖 Agentic AI — Self-Study Curriculum

A hands-on Agentic AI curriculum in Python — from fundamentals to building real agents: Research Agent, Coding Agent, and Personal Assistant. Powered by Groq and LangGraph.

---

## 📚 Curriculum Structure

| Folder | Topic | Key Concepts |
|--------|-------|-------------|
| 01_restAPI | REST APIs | HTTP methods, requests, error handling |
| 02_llmFundamentals | LLM Basics | Tokens, context, system prompts, Groq API |
| 03_asyncPython | Async Python | async/await, asyncio, parallel API calls |
| 04_functionCalling | Function Calling | Tool schemas, parsing responses, multi-tool |
| 05_langGraph | LangGraph | Nodes, edges, routing, ReAct pattern |
| 06_multiAgentSystems | Multi-Agent | Roles, supervisor/worker, CrewAI |
| 07_fastAPI | FastAPI | Serving agents as APIs, routes, models |
| 08_db_auth | DB & Auth | SQLite, agent memory, JWT auth |
| 09_memory | Memory & RAG | Embeddings, ChromaDB, RAG basics |
| 10_promptEngineering | Prompt Engineering | CoT, few-shot, prompt templates |
| 11_frameworks | Frameworks | LangChain, framework comparison |
| 12_projects | Real Projects | Research, Coding & Personal Assistant agents |

---

## 🛠️ Tech Stack

- **Language:** Python
- **LLM Provider:** Groq
- **Frameworks:** LangGraph, LangChain, CrewAI
- **Memory:** ChromaDB
- **Backend:** FastAPI
- **Notebooks:** Jupyter (.ipynb)

---

## 🚀 Projects

### 🔍 Research Agent
Takes a topic, searches the web, and writes a structured report autonomously.

### 💻 Coding Agent
Reads your code, finds bugs, suggests fixes, and explains solutions.

### 🧠 Personal Assistant Agent
Plans your day, reads tasks, and helps manage your schedule intelligently.

---

## 📁 File Convention

- `.ipynb` — concept learning, exploration, experiments
- `.py` — FastAPI servers, agent scripts, auth
- `README.md` — every folder has one with notes and key concepts

---

## ⚙️ Setup

```
git clone https://github.com/MuhammadUsman-Khan/Agentic-AI.git
cd agentic-ai
pip install -r requirements.txt
```

Create a `.env` file:
```
GROQ_API_KEY=your_key_here
```
